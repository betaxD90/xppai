# Development and artifacts

A model belongs to a package; a package is a compilation/deployment unit. A Visual Studio project contains elements from one model; solutions can contain multiple projects. XML model elements are stored separately from project organization. A project reference is not its implementation. .axpp transfers project elements; it is not a production deployment package or XPO.

Identify element and method/property before returning source or designer instructions. Preserve original XML when editing, including unrelated properties and unknown nodes. If metadata is missing, request only what matters. Do not assume a PackagesLocalDirectory path, exact tool version, or environment topology. The unified experience documents Visual Studio 2022; older deployment topologies need their own evidence.
