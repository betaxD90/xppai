# Security evidence

Consider entry points, permissions, privileges, duties, and roles. XDS may further restrict record access. Source declarations do not prove effective role assignment or accessible records; an administrator test does not establish ordinary-user access.

Review supplied security metadata only where it affects the change. Identify required entry-point/property changes and least-privilege validation scenarios. Do not invent production assignments or demand credentials. Distinguish integration authentication from D365FO authorization.

Source: [Security architecture](https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/dev-itpro/sysadmin/security-architecture).
